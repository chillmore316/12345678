如何登记新的候选

可让 Codex 使用本机 CLI 显式选择清单和样本文件；登记完成后点击刷新。此页面只读，不自动获取行情。

.venv311/bin/python -m research_center.cli candidate register \
  --manifest /绝对路径/manifest.json \
  --rows /绝对路径/rows.json --label '候选名称'

登记保留原文件，新快照独立保存。源清单中引用的其他证据不会自动读取或复制。
