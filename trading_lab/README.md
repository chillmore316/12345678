# A股交易训练工作台 · Trading Lab

本地中文日线观察、交易计划、每日复盘与历史模拟训练。React + TypeScript + KLineCharts + ECharts，FastAPI + SQLite。与原 `research_center` 和在线模拟盘分开运行；不连接券商，不自动荐股。

## 在 Mac 上打开

本次工作目录已经准备独立 Python 环境和前端依赖。双击本目录的 **启动交易训练工作台.command**，浏览器访问 **http://127.0.0.1:8090**。保留启动窗口，停止时按 Ctrl+C。

在另一台 Mac 上首次安装，使用 Python 3.11、Node 22，从项目根目录执行：

```sh
./trading_lab/launch.command --setup
./trading_lab/launch.command
```

已有 Python 项目环境不会被修改。遇到端口占用时先查看占用原因；启动器不关闭未知程序。旧研究中心使用8060、旧模拟盘使用8051，与本应用无关。

## 第一次使用

1. **总览**：切换赛腾股份、通信ETF或沪深300，查看来源、未复权日线、MA和成交量。图表可以拖动、缩放、查看十字光标并下载PNG。
2. **每日复盘**：按七个中文问题填写，等待“已保存”；可以完成打卡、按日期查看和搜索。保存内容在本机SQLite，不依赖云账户。
3. **交易计划**：先记录趋势、理由、条件、入场、止损、目标和数量。保存计划不会自动成交；修改有历史记录，已提交委托保留当时的计划快照。
4. **历史模拟**：新建账户，默认本金20,000元，自选缓存覆盖内的已验证交易日作为起点。真实观察持仓不会导入这个空账户。
5. 填写限价、数量和买入止损，确认风险后提交。委托先进入队列；点击“推进下一交易日”才尝试按下一个已验证交易日的真实开盘价模拟成交。未成交余单当日到期，需重新下单；不会推断日内高低价触价成交。
6. 买入当日不可卖出；收盘后可预挂下一交易日生效的卖单。股票与股票ETF均按100股/份买入，价位分别为0.01和0.001元。
7. **账户统计**：完整开平仓才形成一个胜负样本；分批成交、费用和成本由账本处理。未平仓浮盈不会增加胜率。
8. **历史回放训练**：新建训练并选择已有训练即可续接；按1、2或5秒逐步回放。每一步等上一请求结束后才提交下一步，暂停、切换训练、离开页面、切换标签页或进行委托操作都会停止播放。刷新后保持暂停；结果未确认时只允许复用原 UUID 和预期日期重试。
9. 训练结束后账户只读；未平仓持仓保留并单列浮动盈亏。按原条件重新训练会创建新的独立账本，旧账本和统计继续保留。训练复盘和计划按训练账户隔离，复盘日期不晚于训练进度。

止损价用于风险规划，**不会自动触发止损卖单**。模型只模拟开盘尝试，并非券商成交重建；涨停买入、跌停卖出保守不成交。成交容量只参考此前已知成交量，不使用当天结束后才知道的量来决定开盘成交数量。账户行情和日历在创建时冻结，之后同步不会改写旧训练。

## 行情、凭证和数据存储

本机首次检查已取得2026-08-03至2026-11-16三项标的各70根真实日线。它们来自用户指定的第三方Tushare兼容中转，不能称为官方直连或实时行情；页面按收盘历史数据标记。并非所有日期、证券、停复牌和公司行动都已认证。 本轮随后已补齐赛腾和通信ETF的11月17日日线，二者各71根；沪深300的同日请求暂未返回有效数据，保留70根旧缓存。当前训练账户按三项共同窗口冻结，末日仍为11月16日，观察页可查看已取得的11月17日个股/ETF收盘。

凭证优先从进程环境读取，也支持仓库外的本机私有配置：

```text
~/Library/Application Support/TradingLab/.env
TUSHARE_HTTP_URL=http://你的中转地址/tu_share/
TUSHARE_TOKEN=你的特权凭证
TUSHARE_BACKUP_TOKEN=你的积分凭证
```

普通积分接口优先走备用凭证，特权接口可用 `TUSHARE_PRIVILEGED_APIS` 显式指定。不要把真实凭证写进代码、截图、Git或备份说明。请求串行节流，失败进入至少60秒退避；再次刷新页面只读缓存，不自动请求供应商。

数据库默认位于同一私有应用目录的 `trading_lab.sqlite3`。`TRADING_LAB_DB` 可指定独立数据库。真实观察持仓由本机 `profile.json` 初始导入独立观察表，不生成历史买入时间、费用或模拟成交。

“数据管理”支持显式Tushare/AKShare同步和CSV/Parquet导入。来源切换是显式操作，失败保留原缓存；旧账户的冻结快照不变。导入标准列为 `date,open,high,low,close,volume,amount`，可增加 `pre_close,up_limit,down_limit`；标准 volume 为股/份、amount为元。Tushare原生vol/amount单位由适配器专门转换。复权数据不可用于原始价格撮合。

通信ETF的逐日涨跌停接口为空时，程序仅对515880使用注明来源和日期的普通股票ETF 10%规则推导，并明确标注；不能把这个规则推广到所有ETF。缺少日历、涨跌停、前收盘连续性等执行证据时不生成成交；持仓跨公司行动异常时阻止整次推进，不能伪造分红或送股。

## 导出与恢复

数据管理页可以下载JSON备份；账户成交可以导出CSV。备份包含本机训练记录和行情，不包含环境变量或token，请自行保管。

恢复采取保护性导入：在新数据库中验证备份，保留当前数据库。按界面提示使用恢复文件启动后核对账户、复盘、计划和统计；未切换数据库前，当前界面仍为原数据。不要把“备份下载成功”等同于恢复已验收。
