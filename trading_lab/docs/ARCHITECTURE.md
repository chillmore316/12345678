# Trading Lab 技术方案与边界

2026-11-17 本轮新增独立应用，目录 `trading_lab/`。不移动、删除或改写现有研究项目、分钟原始数据及在线账户。旧 `research_center` 的研究报告和旧模拟账户不作为本平台的成交记录。

## 模块

| 模块 | 技术与职责 |
| --- | --- |
| 中文工作台 | React + TypeScript；驾驶舱、日线图、计划、复盘、账户、统计、数据管理 |
| 图表 | KLineCharts；K线、均线、成交量和模拟成交标记；ECharts 展示账户及统计曲线 |
| API | FastAPI；只监听本机，同源访问；显式提交/撤单、推进、同步与导入 |
| 数据 | Tushare 兼容中转 POST；原始日线、交易日历和涨跌停分别取证；AKShare 显式备用，本地文件导入 |
| 账本 | SQLite + Decimal；虚拟账户、委托、成交、持仓、完整交易周期及权益检查点 |
| 训练记录 | SQLite 保存计划、每日复盘及修改历史；观察持仓独立展示，不参与模拟统计 |

## 执行口径

MVP 使用历史日线训练，不提供虚构实时成交。已显示交易日收盘后制定限价委托；手动推进下一交易日时，仅尝试按下一交易日开盘价成交。不会在看完当日行情后按该日开盘价交易，不通过日线最高/最低价推断盘中成交顺序。委托只尝试下一交易日开盘，未成交余单当日到期，不能跨日自动沿用。

603283.SH 和 515880.SH 按100股/份买入单位，分别使用0.01和0.001元最小价位，实施T+1。000300.SH仅作为观察指数。停牌、无可靠日历或涨跌停证据、涨停买入或跌停卖出均保守阻止成交。公司行动未入账时不得跨除权事件伪造收益。训练规则和费用并非真实券商执行承诺。

原始价格用于模拟记账。复权数据不能转换成成交价格。缓存明确记录来源、价格口径和更新日期，失败时保留已保存数据并显示原因，不自动换源。实时模拟盘和券商接口不在本轮范围。

## 数据权限与凭证

中转服务为用户提供的第三方服务，并非 Tushare 官方直连。普通积分接口优先使用 `TUSHARE_BACKUP_TOKEN`；特权接口使用 `TUSHARE_TOKEN`。网络请求串行节流；失败进入至少60秒补偿等待，禁止立即循环重试。默认独立直连，避免继承本机不兼容 SOCKS 代理。所有凭证通过进程环境或仓库外的私有 `.env` 加载，不随备份和导出返回。

## 验收顺序

1. 真实赛腾、通信ETF与沪深300日线缓存及来源标签。
2. 中文图表中均线、成交量、交互与买卖标记。
3. 复盘保存、刷新后读回及修改历史。
4. 独立账户委托、撤单、推进、T+1和完整开平仓统计。
5. 合成单元测试、真实数据本地训练、浏览器完整流程、全新只读复核分别报告。

第二阶段扩展12周学习计划、速度控制、训练任务比较、更多公司行动与执行模型，不把未实现页面或占位数据视为完成。
